# 世界模型幻觉 · World Model Hallucinations

这个仓库收集**世界模型幻觉**的文献、诊断方法和研究笔记，重点关注视觉生成式、动作条件及潜空间世界模型在具身系统中的可靠性与安全性。

这里的「幻觉」不是指画面不够逼真，而是指模型在给定观测历史和动作后，预测了与可验证证据不符的状态、转移或事件。例如，模型预测物体在搬运中保持稳定，但相同条件下的传感器或重复试验显示它容易滑落。一个未来有多种物理上合理的结果，或单次概率预测落空，本身不算幻觉。

## 研究重点

- **诊断**：区分状态表征错误、忽略动作、错误预测动作后果，以及多步推演中的误差累积。
- **评测**：用动作干预、物理观测和重复试验检查预测是否忠实，而不只看生成视频是否逼真。
- **具身安全**：关注错误预测会不会让规划器把危险动作排在安全动作之前，以及何时应再观测或拒绝放行。
